# Mongolian Traditional Character Dataset (MTCD)

The **Mongolian Traditional Character Dataset (MTCD)** is a full stack web application with aim to collect handwritten Mongolian traditional script characters, designed to support research and development in handwriting recognition, OCR, and educational tools for the traditional Mongolian script.


##  Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/13aba/MTCD.git
cd MTCD
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Set up & Start the server

```bash
python manage.py migrate
python manage.py runserver
```
